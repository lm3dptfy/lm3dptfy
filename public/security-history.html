Advisory OWASP MCP Top 10 Formalized at MCP Dev Summit Seoul — Systemic Protocol-Level Risk (Aug 11-14, 2026)
The MCP Dev Summit in Seoul (Aug 13-14, 2026) became a "high-stakes confrontation" between MCP's protocol designers and the security community over the formalization of the OWASP MCP Top 10 (MCP01:2025-MCP10:2025, covering risks like token mismanagement and tool poisoning). Researchers reported over 21,000 internet-facing MCP server instances exposed, ~92% of audited production servers lacking basic OAuth authentication, 687 instances with unrestricted shell tool access, and 10+ critical/high-severity CVEs disclosed against MCP implementations in 2026. The core dispute is architectural: security researchers argue the STDIO transport model needs fundamental hardening, while Anthropic maintains the current design is intentional. Protocol governance has moved to the Linux Foundation's Agentic AI Foundation as a neutral venue. Not a single CVE — a protocol-wide posture issue. If you run self-hosted or third-party MCP servers, audit for OAuth enforcement and unrestricted shell-tool access against the OWASP MCP Top 10 checklist. Forkast · Cycode: OWASP MCP Top 10 Guide
Advisory Claude Code Action git push --receive-pack Command-Validator Bypass — No CVE, Fix Unconfirmed (Disclosed Aug 5, 2026)
Disclosed at Black Hat USA (Aug 5, 2026) by the same researcher (hackerone.com/novee) behind CVE-2026-54316. Claude Code's command validator strips single-quoted text before running its 23 security checks — correct behavior for how bash itself interprets quoting, but it means a malicious payload placed inside the quoted value of git's --receive-pack flag (which git executes) reaches the runner without ever being inspected. In Claude Code Action's tag mode, an attacker with no repository privileges could trigger this via a crafted GitHub issue, achieving remote code execution on the CI runner and reading GITHUB_TOKEN/ANTHROPIC_API_KEY from the environment. Unlike CVE-2026-54316 (fixed v2.1.163, see Resolved), no CVE has been assigned to this specific bypass and no fixed version has been publicly confirmed. If you use Claude Code Action / tag mode in CI, review workflow permissions and avoid granting write-scoped secrets to runners that process untrusted issue/PR content. The Hacker News
