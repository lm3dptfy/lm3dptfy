Context7 MCP v4.0.0 — Breaking Change: MCP SDK v2, Stateless HTTP & Bearer Auth (Aug 7, 2026)
Context7 v4.0.0 (released ~Aug 7) migrates to the MCP v2 SDK and the 2026-07-28 protocol spec. Breaking changes: HTTP serving is now stateless (Redis-backed sessions removed); API key config changes from a custom header to Authorization: Bearer <key> standard format (ctx7 setup handles this automatically for new installs). If you have a custom MCP proxy, credential manager, or pinned client that relied on the old auth header or Redis session state, update your config before upgrading. Context7 remains the #1 server on MCP.Directory. Update: npm install -g @upstash/context7-mcp

MCP 2026-07-28 Spec Live (Day 12) — SSE Transport Removed, All Integrations Must Migrate
Day 12 of the MCP 2026-07-28 spec. SSE transport is officially gone. Any server or client still on SSE is no longer spec-compliant. Context7 v4.0.0 has fully migrated. Check Google Workspace MCPs (Gmail/Drive/Calendar), Canva MCP, Three.js MCP, and any custom SSE-based integrations. New spec requires Mcp-Method/Mcp-Name headers from clients and a server/discover endpoint on servers. Mid-conversation tool changes are in beta via mid-conversation-tool-changes-2026-07-01 header.

Anthropic Building In-House Custom Chip Design Team (Aug 8, 2026)
Anthropic is assembling an in-house chip design team to run Claude faster and more cost-efficiently, reducing dependence on third-party hardware vendors.
