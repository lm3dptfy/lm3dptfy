Auto Mode Becomes Default in Claude Code for Pro, Max & Team — Aug 14, 2026
Starting Aug 14, Claude Code's auto mode — a safety classifier that approves routine actions and only pauses for irreversible/destructive/out-of-environment actions — replaces manual per-action approval as the default for Pro, Max, and Team plans. Anthropic's study of 1,053 paid testers found the classifier caught 89% of harmful actions vs. 13.6% for human review; token charges for classifier overhead are being dropped on these plans. Three consecutive blocks or 20 total in a session reverts the whole session to manual approval. Enterprise/API/cloud-platform users stay opt-in for now, with default rollout there planned "within the coming month."

Context7 MCP v4.0.0 — Breaking Change: MCP SDK v2, Stateless HTTP & Bearer Auth (Aug 7, 2026)
Context7 v4.0.0 (released ~Aug 7) migrates to the MCP v2 SDK and the 2026-07-28 protocol spec. Breaking changes: HTTP serving is now stateless (Redis-backed sessions removed); API key config changes from a custom header to Authorization: Bearer <key> standard format (ctx7 setup handles this automatically for new installs). If you have a custom MCP proxy, credential manager, or pinned client that relied on the old auth header or Redis session state, update your config before upgrading. Context7 remains the #1 server on MCP.Directory. Update: npm install -g @upstash/context7-mcp
