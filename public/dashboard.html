List Claude Code dependencies
click to copy ls /opt/homebrew/lib/node_modules/@anthropic-ai/claude-code/node_modules/
Check GitHub security advisories for Claude Code
click to copy gh api repos/anthropics/claude-code/security-advisories --jq '.[0:5] | .[] | {cve_id, summary, severity, published_at}'
Rotate Anthropic API key (open settings)
click to copy open https://console.anthropic.com/settings/keys
View all installed MCP servers
click to copy cat ~/.claude/settings.json | python3 -m json.tool | grep -A2 '"mcpServers"'
List Claude Code plugins
click to copy ls ~/.claude/plugins/ 2>/dev/null || echo "No plugins directory found"
Audit Claude Code permissions (show current mode)
click to copy cat ~/.claude/settings.json | python3 -c "import json,sys; d=json.load(sys.stdin); print('Mode:', d.get('permissions',{}).get('defaultMode','not set'))"
