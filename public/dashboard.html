🚨 Security Alerts
Active and resolved CVEs, supply chain incidents, and advisories.
Advisory CVE-2026-24052 — Domain Validation Bypass Allows Requests to Attacker-Controlled Domains — Apr 2026
Claude Code contained insufficient URL validation in its trusted domain verification mechanism for WebFetch requests, allowing an attacker to craft URLs that bypassed the allowlist check and caused Claude Code to automatically issue requests to attacker-controlled domains — potentially leaking session context or API credentials. Patch available in a recent release; update immediately via claude update. GitLab Advisory
Advisory GHSA-q5hj-mxqh-vv77 — Trust Dialog Bypass via Git Worktree Spoofing — Apr 24, 2026
Published TODAY. High severity. An attacker can craft a git worktree that spoofs workspace trust context, bypassing the trust dialog and allowing arbitrary code execution without user confirmation. No CVE number assigned yet. Check GitHub for patched version. Avoid opening unfamiliar git worktrees until patched. GitHub Advisory
Resolved CVE-2026-39861 — Sandbox Escape via Symlink Following — Apr 2026
Claude Code's sandbox did not prevent sandboxed processes from creating symlinks pointing outside the workspace. When the unsandboxed process subsequently wrote to that symlink path, it followed the link and wrote to arbitrary locations, enabling code execution outside the sandbox. Exploitation required the ability to inject untrusted content into the Claude Code context window to trigger sandboxed code execution. Fixed in v2.1.64. Users on auto-update are protected. GitLab Advisory · CVEReports
Advisory CVE-2026-35603 — Windows Local Privilege Escalation via Insecure ProgramData Config — Apr 2026
On Windows, Claude Code loaded system-wide default configuration from C:\ProgramData\ClaudeCode\managed-settings.json without validating directory ownership or permissions. Because ProgramData is writable by non-admin users and the ClaudeCode subdirectory was not pre-created or access-restricted, a low-privileged local user could plant a malicious config file that executes for any user launching Claude Code on the same machine. CVSS 4.0 base score 5.4 (Moderate). Patched in v2.1.75 — update immediately on any shared Windows system. GitLab Advisory
Advisory GHSA-mmgp-wc2j-qcv7 — Workspace Trust Dialog Bypass via Repo-Controlled Settings File — Mar 18, 2026
High-severity: a malicious repository can include a .claude/settings.json that bypasses the workspace trust dialog, allowing the repo to execute code with elevated trust before user approval. Patched in recent releases. Always inspect .claude/settings.json in cloned repos before opening. GitHub Advisory
Advisory CVE-2025-59536 / CVE-2026-21852 — RCE & API Token Exfiltration via Project Files
Check Point Research found attackers can achieve remote code execution and steal API credentials through malicious Claude Code project configurations — exploiting Hooks, MCP servers, and environment variables. CVE-2025-59536 published Oct 3 2025; CVE-2026-21852 published Jan 21 2026. Review untrusted CLAUDE.md files and MCP configs before use. Check Point Research
Advisory CVE-2026-35020 / 35021 / 35022 — CLI Command Injection Chain → Credential Exfiltration
Three newly disclosed CWE-78 command injection flaws in the Claude Code CLI can be chained to exfiltrate Anthropic API keys. Patch to v2.1.92+. Phoenix Security
Critical Claude Code Post-Leak RCE Vulnerability — Apr 5, 2026
A critical vulnerability emerged days after the v2.1.88 source map leak, enabling remote code execution. Patch available in v2.1.92+. Update immediately if on v2.1.88–2.1.91. SecurityWeek
Resolved Claude Code Deny Rules Bypass — 50-Subcommand Chain — Apr 1, 2026
Adversa (Tel Aviv) disclosed that Claude Code silently skips all deny-rule enforcement when a shell pipeline exceeds 50 subcommands (joined with &&, ||, or ;), falling back to a generic auto-approvable prompt. Attackers with repo access could prepend 50 harmless statements to sneak blocked commands like curl or rm past configured deny rules. Fixed in v2.1.90 (Apr 4). Update if below v2.1.90.
